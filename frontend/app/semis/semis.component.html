Fiche de Semis :
Numéro de Semis Le numéro de semis est obligatoire. Le numéro de semis doit respecter le format SAAAA_NNNN (ex. : S2026_0001). L’année du semis doit correspondre à la date de début. Le numéro d’ordre du semis ne peut pas être 0000.
Date de début La date de début est obligatoire. L’année du semis doit correspondre à l’année de début. Date de fin
La date de fin doit être postérieure à la date de début.
Méthode *
La méthode est obligatoire.
Substrat *
Le substrat est obligatoire.
Contenant Le contenant est obligatoire. Profondeur (mm) La profondeur est obligatoire. La profondeur doit être supérieure à 0.
Mode d'arrosage *
Le mode d’arrosage est obligatoire.
Personne ayant effectué le semis *
La personne ayant effectué le semis est obligatoire.
Nombre de graines semées Le nombre de graines semées est obligatoire. Le nombre de graines semées doit être supérieur à 0. Nombre de réplicats Le nombre de réplicats est obligatoire. Le nombre de réplicats doit être supérieur à 0.
Localisation *
La localisation est obligatoire.
